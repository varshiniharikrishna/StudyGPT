# StudyGPT

StudyGPT is an AI-powered study assistant developed using Streamlit and Ollama. The application allows users to upload PDF documents, interact with the content through natural language, and receive AI-generated responses based on the uploaded material.

## Features

- Upload and process PDF documents
- Ask questions about the uploaded content
- Generate concise summaries
- Interactive web interface built with Streamlit

## Technologies Used

- Python
- Streamlit
- Ollama
- PyPDF
- Scikit-learn

## Installation

Clone the repository:

```bash
git clone https://github.com/varshiniharikrishna/StudyGPT.git
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
